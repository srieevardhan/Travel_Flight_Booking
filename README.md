# Travel Flight Bookings Dashboard – Power BI

## 📌 Project Overview

The **Travel Flight Bookings Dashboard** is an interactive Power BI project designed to analyze airline booking performance, revenue trends, passenger behavior, and flight operations. The dashboard enables users to monitor key business metrics through dynamic visualizations, helping stakeholders make data-driven decisions.

The project is divided into three analytical dashboards:

1. Executive Revenue & Booking Overview
2. Flight Operations & Booking Status
3. Passenger & Payment Analytics

---

## 📊 Dashboard 1: Executive Revenue & Booking Overview

### Key KPIs

* Total Revenue
* Distinct Bookings
* Average Fare
* Net Fare
* Discount Percentage

### Visualizations

* Monthly Revenue Trend
* Revenue by Airline
* Revenue Distribution by Fare Class
* Origin-wise Revenue (Map)
* Booking Details Table

### Business Insights

* Tracks monthly revenue performance.
* Identifies top-performing airlines.
* Analyzes fare class contribution to revenue.
* Displays revenue generated from different origin cities.
* Provides booking-level details for operational analysis.

### Visualizations

* Average Fare vs Ticketed Rate
